# Aditya-L1 Mission Simulation

## Overview
This project is an interactive **Aditya-L1 mission simulation** made using **p5.js**. It shows the journey of the spacecraft from **rocket launch**, **stage separation**, **satellite deployment**, **orbit transfer**, and **L1 halo orbit** to **scientific payload visualization**.

## Features
- Rocket launch animation  
- Stage separation  
- Satellite deployment  
- Earth orbit transfer  
- L1 Halo Orbit simulation  
- Lagrange point visualization  
- Interactive scientific payloads  

## Technologies Used
- JavaScript  
- p5.js  
- p5.sound  
- HTML/CSS  

## Controls
- **Mouse Click:** Launch rocket and continue stage separation  
- **Click Payload Buttons:** View payload information
